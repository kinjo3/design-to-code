# 差分チェック

実装後、`design-diff` が見本画像（Figma の書き出し画像、またはデザイン画像）と実装の描画結果を比べる。

## 合格の条件

差分は 2 つで測り、両方を満たせば合格とする。

- 箱のずれ: Figma の各ノードと実装の要素を突き合わせた箱（位置と寸法）のずれが `--layout-tolerance`（既定 1px）以内。Figma の URL から実装する場合だけ測る。
- 画素の差分: 比較した画素のうち差分のある画素の割合 `diffRatio` が `--threshold`（既定 0.02）以下。

素材が提供されずプレースホルダーで実装した写真やアイコンは、見本画像と実装の両方の比較から外す。外した画素は `diffRatio` の分母にも分子にも入らない。

## 出力

比較のたびに `.design-diff/<selector>-<width>/` へ次のファイルが上書きされる。

| ファイル | 中身 |
| --- | --- |
| `design.png` | 見本画像 |
| `actual.png` | 実装の描画結果 |
| `diff.png` | 差分のある画素。比較から外した範囲は青で塗られる |
| `compare.png` | `design.png` `actual.png` `diff.png` を縮小して横に並べた画像。比較から外した範囲は青で塗られる |
| `summary.json` | 合否・`diffRatio`・差分のある画素の固まりの位置・比較から外した範囲（`excludedCssPx`） |
| `layout.json` | ノードごとの箱のずれ。Figma の URL から実装した場合だけ出る |

## 差分チェックの完走

`/design-to-code` を呼んだセッションでは、スキルの Stop hook が有効になる。settings.json への追記は要らない。スキルが登録したセレクタと幅の組のどれかが、合格も調整 3 回での打ち切りもしていないまま Claude Code が終えようとすると、hook が理由（未実行・未合格・合格後に未再実行）を返して終了を止める。

合格後に未再実行かどうかは、計測時と終了時の作業ツリーのハッシュ（HEAD と、コミットしていないファイルの中身から求める）を比べて決める。git で管理していないプロジェクトと、親のリポジトリが `.gitignore` などで除外しているディレクトリでは、合否と調整回数だけで判定する。前回止めたときから実行記録も作業ツリーも変わっていなければ、同じ理由では止めない。

Stop hook はサンドボックスの外で動く。登録はセッションごとに `.design-diff/sessions/<セッション ID>.json` へ、実行記録は `.design-diff/<selector>-<width>/runs.jsonl` へ残る。
